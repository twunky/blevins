## Limitations

- Verification is by the implementing agent. The SQL tests exercised temporary local databases; this is not evidence of deployment or application of the migration to another environment.
- Permanent revocation relies on membership-ending application paths invoking `FamilyGroupMembership.End()`, which advances `AccessVersion`. Future membership write paths must preserve that invariant.
- After a creator leaves the group, own-Trip view and edit remain available. The Angular group directory is deliberately unavailable; therefore adding a new traveler through its picker after departure is not provided. Existing traveler entries and core Trip details remain editable, while repository authorization still validates newly supplied traveler IDs. A future UX slice can address this rare case without broadening group-directory access.
