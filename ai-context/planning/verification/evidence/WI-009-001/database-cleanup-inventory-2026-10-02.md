## Method

Only catalog metadata was read: `sys.databases` (name, creation date, state, owner), `sys.master_files` (size), `sys.dm_exec_sessions` (open sessions), and the row count of each database's `dbo.__EFMigrationsHistory` (a schema marker). **No application table contents were read.** Provenance came from the repository: the Playwright configuration history, the scenario script, the .NET test sources, and citations in verification records.

All 82 databases are `ONLINE` and owned by `SBLEVINS\seanb`. Each is 16 MB, except one at 80 MB. None has open sessions, and all carry the application's EF schema (1–12 migrations). So schema and size do not separate test databases from the others. The classification rests on **how each name is generated** and **whether a record depends on the database**. A `FamilySafety` prefix was never enough on its own.

Classifications:

- **A. PRODUCTION/DEFAULT — NEVER DELETE**
- **B. CURRENT-RUN RETAINED DIAGNOSTIC** — created and retained by a `WI-009-001` harness run.
- **C. CLEAR LEGACY TEST DATABASE** — created by an automated test or harness whose naming rule and lifecycle are defined in code.
- **D. UNCERTAIN — DO NOT DELETE** — manually named, cited as evidence, or of unknown owner intent.
