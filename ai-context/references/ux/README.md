# UX Mockup References

These images are visual design references only. They may help with layout direction, information hierarchy, workflow concepts, visual style, page composition, and possible interaction patterns.

They are **not** canonical product requirements. Visible controls, navigation items, labels, fields, tabs, buttons, states, permissions, and workflows are not approved merely because they appear in an image. Some concepts are exploratory and may change or be removed.

Canonical contracts, requirements, privacy rules, approved workflows, and approved work items take precedence. Mockups cannot introduce requirements, resolve open decisions, expand permissions, or authorize functionality. Use them as a starting point for UX implementation and discussion.
