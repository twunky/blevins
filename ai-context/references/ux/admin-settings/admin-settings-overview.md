# Admin and Settings Overview

Status: REFERENCE ONLY

Useful direction:
- Separate family administration from personal privacy and notification settings.
- Make membership and invitation information easy to scan.
- Place access and privacy context close to related settings.

Cross-domain relevance: Family membership and sharing privacy appear here as settings concepts.

Exploratory elements: Roles, permissions, family groups, persistent location sharing, access review, notification options, and invitation history require separate approved rules; administrator access does not imply access to private data.

Not authoritative: exact navigation, labels, fields, tabs, button placement, permissions, or business rules.
