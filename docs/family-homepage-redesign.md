# Family homepage implementation

Current behavior remains governed by CTX-1.39, the [product contract](../ai-context/core/product-contract.md), and the [privacy contract](../ai-context/core/privacy-safety-contract.md). Presentation follows the [UI Visual Design Contract](../ai-context/ui-visual-design-contract.md). This note records the October 8, 2026 implementation; it does not claim human usability approval or Phase 10 closure.

The desktop homepage places Household and Shared Family Date summaries beside the directory; narrow layouts show members first. Search filters authorized directory results by display name, case-insensitively, without extra API reads. Initials replace photos; complete long names remain accessible. Summaries show up to four rows and link to existing management workflows. Dates come from the authorized date API, never private profile fields. Household management authority remains server-derived.

Member links open `/family/:familyId/members/:profileId`. The view validates identifiers, reads that Family's authorized directory, confirms membership, and reads `/api/family-members/:profileId/profile` before adopting authorized Family context. It displays only server-projected name, shared email/phone, and birthday month/day, without editing. Missing and denied resources share the unavailable state. Refresh clears old fields; departed-view guards prevent stale adoption. Self links open `/me`; Family switching clears the member view and search.

Implementation references: [member profile](../src/FamilySafety.Web/src/app/member-profile/member-profile.ts), [Family dashboard tests](../src/FamilySafety.Web/src/app/family-dashboard.spec.ts), and [reusable browser checks](../src/FamilySafety.Web/e2e/family-homepage.ui.ts).

Recorded technical verification: 59 focused Angular tests; 427 tests across 28 files in the broader regression; production build passed with existing budget warnings. Browser checks covered 1440/768/390px, 20 members, long names, search/clear/empty state, keyboard focus, member refresh, denied reads, self routing, Family switching, management navigation, no overflow, and zero axe violations in tested states. Later visual-alignment checks passed nine focused Family tests and the three-width browser review. Database-backed Family journeys updated during this redesign were not executed because the existing API port was occupied; running databases were preserved. Disposable logs and screenshots were removed after consolidation. These are historical self-verification results, not fresh cleanup test results.
